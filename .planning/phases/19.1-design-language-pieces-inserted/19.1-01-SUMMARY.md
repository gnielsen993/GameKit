# Phase 19.1 Plan 01: Wave 0 Spikes Summary

**Six SwiftUI assumptions measured on the simulator: five PASS, and A1 FAILS because `.fontDesign(.rounded)` also overrides the monospaced timer font, so rounded type must be an explicit-design Font helper.**

- **Completed:** 2026-11-27

## Accomplishments

- A1 FAIL: `ImageRenderer` pair comparison showed `.fontDesign(.rounded)` changes `title`, `headline` (wanted) but also `monoNumber` and an explicit serif probe (not wanted). Plan 02 uses `RoundedType.font(_:weight:)`.
- A8 PASS (rounded heavy digits with `.monospacedDigit()`: widths 80.0 and 80.0; control 62.3 vs 81.0). A2 PASS (`@AppStorage` inside a `ButtonStyle` updates live in 0.046 s).
- A3 PASS: counter-triggered per-cell `KeyframeAnimator` fires once, reads the step at trigger time, does not re-fire on clear, 81 cells with max frame gap 18 ms in a Debug build.
- A4 PASS on iPhone SE (3 taps, 6 press transitions); the control variant also passed, so the test cannot prove `contentShape` is required.
- A6 PASS: `simctl ... defaults write ... ReduceMotionEnabled` plus an app relaunch flips `accessibilityReduceMotion`; reset to false afterwards.
