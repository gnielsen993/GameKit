<objective>
Run the four Wave 0 spikes the research asked for, plus two cheap checks that later plans depend on, and write the verdicts down before any production code exists.

Purpose: the piece style (plan 02), the per-cell wave (plan 03) and the motion-off automation (plan 06) each rest on a SwiftUI behaviour the research could not confirm from documentation. A spike costs minutes; discovering a wrong assumption after the pad, the cells and the win are built costs a rework of all three.

Output: `19.1-SPIKES.md` in the phase directory. No production code. This plan is Wave 0, so it has no tracer task; the phase tracer is 19.1-02 Task 1.

Assumptions covered (RESEARCH.md "Assumptions Log"):
- A1: `.fontDesign(.rounded)` rounds text-style token fonts and does not override fonts that carry an explicit design (`monoNumber`, `titleLarge`).
- A2: an `@AppStorage` property read inside a `ButtonStyle` invalidates the style live.
- A3: `KeyframeAnimator` fires once per trigger change, reads per-cell props at trigger time, and is cheap across 81 cells.
- A4: a `.contentShape(Rectangle())` on the un-offset outer frame stops press/un-press jitter when the top edge of a sinking face is tapped on iPhone SE.
- A6: `xcrun simctl spawn <udid> defaults write com.apple.Accessibility ReduceMotionEnabled -bool true` turns Reduce Motion on in the simulator.
- A8: SF Rounded keeps tabular digits under `.monospacedDigit()`.
</objective>
