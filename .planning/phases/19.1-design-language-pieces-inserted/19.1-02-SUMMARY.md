## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] PieceSpec types made `nonisolated`**
- **Found during:** Task 1 (first test build)
- **Issue:** the module defaults to main-actor isolation, so the pure geometry could not be called from a `nonisolated` Swift Testing suite.
- **Fix:** `nonisolated` on `PieceSize`, `PieceSpec`, `PieceGeometry`, and on the DEBUG enum and extension in `PieceTuning.swift`. No behavior change.
- **Commit:** `c64a8fe`

**2. [Rule 1 - Bug] Contact shadow placement**
- **Found during:** Task 1
- **Issue:** applying the specified `y: depth + 3` helper to the already-offset edge would double the offset.
- **Fix:** for `.large` only, a face-position layer behind the edge casts the shadow, so the helper keeps its documented meaning. No large piece ships in this plan; visual check is deferred to the plans that add one (Settings DEBUG preview shows one).
- **Commit:** `c64a8fe`

**3. [Rule 1 - Test pollution] UI tests left a saved game with a placed wrong digit**
- **Found during:** Task 2 regression run: `testDeepLargeText` and `testSmallSudokuAndBackgroundTimer` failed ("Fill it in" not found) because the resumed board held a red mistake from my pad tests, so the hint was "Check the red squares".
- **Fix:** the pad tests now tap Erase at the end; app uninstalled from the simulator once; both regression tests re-ran green.
- **Commit:** `3db0369`

**4. [Process] RED evidence is a build failure, not a classified RED**
- Task 3 is `tdd="true"`. I wrote the DEBUG tests first and ran them: the build failed (`PieceStrength`, `PieceSpec.subtle/bold/resolved` missing). That is a `build_failure`, not a valid RED under tdd.md, and the plan asks for one commit holding tests and code, so there is no separate `test(...)` commit and `gsd_run check tdd-red-evidence` was not run. The plan is `type: execute`, not `type: tdd`, so no plan-level gate section applies.

**5. [Process note] DESIGN.md and this SUMMARY committed on main** per the plan and CLAUDE.md 8.18; the generic protected-branch guard was not applied to document commits.

**Total deviations:** 3 auto-fixed, 2 process notes. **Impact:** none on scope.
