## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Debug build to Release build | DEBUG-only tooling (strength switch, near-win fixture, Debug menu) must not exist in a shipped binary | Symbols, launch arguments, a UserDefaults key |
| Debug fixture to the player's data | A fixture game must not write to GameStats or the saved-puzzle slot | Stats rows, best times, saved board |
| Release line `2.0` to `main` | A half-converted design language must not reach the shipped branch | App code commits, tags |
| GameStats to the win card | The "personal best" claim must come only from the stats evaluation | `RecordResult.setBestTime` |
